# 00_SCOPE_MVP — NADU (MVP Scope Freeze)
_גרסת GOLD: 2026-01-12_

## מטרה
לנעול **מה נכנס ל‑MVP ומה לא**, כדי להקים אתר מהר בלי Feature‑Creep.

## MVP — מה כן (IN)
### זהות וכניסה
- Firebase Auth: Email/Password (+ אימות), אופציונלי Google/Apple.
- 18+ (DOB) + חסימה מיידית למי שלא עומד בדרישה (Server authoritative).
- פרופיל בסיסי: תמונה/אווטאר, displayName, bio קצר, מיקום כללי (region).

### פוסטים ותגובות
- יצירת פוסט, צפייה בפיד, צפייה בפוסט בודד.
- תגובות לפוסט.
- אנונימיות ברמת פוסט (isAnonymous) לפי חוקי פרטיות.

### צ'אט
- 1:1 בלבד ב‑MVP.
- חסימות (block) + דיווח (report).
- גייטינג לפי ותק מינימלי (למשל 7 ימים) לצמצום ספאם.

### מודרציה ודיווחים
- Report על פוסט/תגובה/הודעה.
- כל פעולת מודרציה נרשמת ל‑audit log.

### תשתית
- Firestore + Security Rules (Default deny).
- Cloud Functions / API שכבת שרת מחייבת לכל write משמעותי.
- App Check חובה לפני קריאות API.

## MVP — מה לא (OUT)
- קבוצות/אירועים/חנות משתמשים.
- וידאו/קול בצ'אט, צ'אט קבוצתי.
- תשלומים/פרימיום.
- מערכת חיפוש מתקדמת, המלצות AI, פיד אלגוריתמי.
- העלאת מדיה מורכבת (וידאו/אלבומים/סטוריז).
- CI/CD מורכב, observability מתקדם (ב‑MVP: מינימום).

## קריטריון יציאה ל‑Phase 2
- אתר רץ בפרודקשן, Auth עובד, פוסטים עובדים, צ'אט 1:1 עובד, דיווח/מודרציה עובד.
- Smoke tests ידניים מוגדרים ומבוצעים אחרי כל deploy.
