# 81_PWA_STRATEGY.md
_עודכן לאחרונה: 2026-01-08_

## מטרה
לאפשר חוויית “אפליקציה” שניתנת להתקנה בלי להיכנס מיד ל־Native.

## המלצה
להתחיל ב־**Mobile Web + PWA**:
- התקנה למסך הבית
- ניווט בסגנון אפליקציה
- Service Worker לשיפור ביצועים (קאש רק לתוכן לא רגיש)

להשאיר מסלול עתידי ל־Native wrapper אם נדרש (Push עקבי וכו').

## מה כן/לא בקאש
### כן
- shell של האפליקציה (UI בסיסי)
- אייקונים/פונטים/קבצים סטטיים

### לא
- הודעות צ׳ט פרטיות
- פרופילים פרטיים
- מדיה רגישה
אלא אם יש הצפנה מקומית ומדיניות ברורה (בשלב מתקדם).

## Push
- אנדרואיד: לרוב אפשרי
- iOS: תלוי תמיכה בגרסה/תנאים

## חוויית התקנה
- מסך “התקן את NADU”
- הסבר שזה עדיין Web (אם לא Native)

## עדכונים
- Toast “יש גרסה חדשה”
- רענון רק ביוזמת המשתמש

## Definition of Done
- התקנה עובדת באנדרואיד כרום.
- אין “מסך לבן” בעדכונים.
