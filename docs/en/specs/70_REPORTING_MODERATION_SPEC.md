# Reporting, Blocking & Moderation Specification

## Purpose
Provide a safe, transparent, and effective reporting and moderation system for NADU.

## Report Types
- Post report
- Comment report
- Private message report
- Profile report

## Report Reasons
- Harassment / Threats
- Illegal content
- Consent violation
- Impersonation
- Spam

## Moderation Flow
1. User reports content
2. Incident is created
3. Automated classification
4. Moderator review
5. Action: warning / block / removal

## Blocking
- One-way block
- Mutual block
- View restriction
- Contact restriction

## Transparency
- Action logs
- User notifications
- Appeal process
