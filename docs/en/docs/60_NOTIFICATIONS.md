# 60 — Notifications

**Last updated:** 2026-01-07  
**Type:** HOW

## 1. Channels
- In-app (badge counters)
- Push (FCM) — mobile-first

## 2. Events (v1)
- New purple DM message
- New red DM message (inbox)
- Mention/reply on a post comment
- Report status updates (optional, admins only)

## 3. Delivery rules
- Respect privacy & blocks (do not notify about hidden content).
- Rate-limit bursts (chat rooms).
