# Chat Product Specification

## Chat Purpose
Enable safe, private, and respectful communication between users.

## Chat Types
- One-to-one
- Group
- Anonymous (based on settings)

## Features
- Text
- Emojis
- File sharing (limited)
- Message deletion
- Blocking

## Privacy
- Encryption
- Screenshot prevention (mobile)
- History deletion

## Rules
- Mutual consent
- Quick reporting
- Spam prevention
