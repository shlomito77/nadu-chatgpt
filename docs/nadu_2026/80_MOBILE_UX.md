# 80_MOBILE_FIRST_UX.md
_עודכן לאחרונה: 2026-01-08_

## מטרה
להגדיר כללי UX “Mobile-first” ל־NADU כך שהמוצר יתנהג עקבי באייפון/אנדרואיד (דפדפן) ובמידת הצורך גם כ־PWA.

זה מסמך **כללים והתנהגות** (לא קוד).

## עקרונות
- **מובייל הוא ברירת המחדל**: דסקטופ משני.
- **שימוש ביד אחת**: פעולות עיקריות בתחתית המסך.
- **מהירות מורגשת**: Skeletons, טעינה הדרגתית, מינימום חיכוך בניווט.
- **פרטיות כברירת מחדל**: לא חושפים מידע רגיש ב־preview/התראות/שיתוף.

## ניווט גלובלי (מובייל)
### Tab Bar תחתון (מומלץ)
טאבים:
1. בית / פיד
2. פוסטים
3. צ׳ט
4. התראות
5. פרופיל (“אני”)

כללים:
- צ׳ט חייב להיות טאב מרכזי.
- מונים (badges) להודעות/התראות.
- מניעת אובדן טקסט בזמן כתיבה (draft protection).

## רישום/התחברות (מובייל)
- מינימום שדות בכל מסך.
- מקלדות מותאמות (אימייל/מספרים).
- ולידציה בזמן אמת, בלי מודלים מעיקים.
- Microcopy “למה אנחנו מבקשים”.

## צ׳ט (מובייל)
- קומפוזר קבוע בתחתית:
  - טקסט + אימוג׳י
  - Reply להודעה (אם נדרש)
  - Report/Block ב־Long-press או תפריט
- רשימות ארוכות:
  - Virtualization
  - “קפוץ להכי חדש”
- שימור טיוטה בהחלפת מסכים/מינימייז.

## פוסטים (מובייל)
- פיד גלילה אנכית.
- מדיה:
  - Tap להגדלה
  - טשטוש תוכן רגיש לפי כללי פרטיות
- תגובות:
  - שרשורים מתקפלים
  - “הוסף תגובה” נגיש תמיד

## פרופיל (מובייל)
- “כרטיסים” ומידע קריטי למעלה.
- עריכת פרופיל:
  - לפי סעיפים (wizard) ולא טופס ארוך
  - שמירת טיוטה + “פרסם שינוי”

## נגישות ורב־לשוניות
- RTL (עברית) כבסיס: יישור/כיווניות תקינים.
- תמיכה בגדלי טקסט.
- מינימום שטח מגע (Touch targets) גדול.

## רשת חלשה / אופליין
- חיווי אופליין ברור.
- קריאה מקאש רק אם בטוח.
- לא לקאש צ׳טים/מדיה פרטית בצורה לא בטוחה.

## Definition of Done
- עובד מצוין ב־360x800.
- בלי גלילה אופקית.
- safe-area תקין.
- המקלדת לא מסתירה פעולות קריטיות.
