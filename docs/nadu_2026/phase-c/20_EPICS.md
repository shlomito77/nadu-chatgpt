# Phase C — Epics

## Epic 1: Auth & Onboarding
- Providers: Email/Password+Phone verification, Google, Apple
- Account linking rules
- Onboarding gate: no profile => no access

## Epic 2: Profile & Privacy
- Create/Edit Profile
- Privacy security settings (anti-screenshot policy UX + deterrence)
- Username policy: allowed chars (Heb/Eng/Digits), 30-day change window
- Locked fields: sex, DOB

## Epic 3: Posts
- Public feed (logged-in only site)
- Anonymous posts/comments (visible as Anonymous to users; admin sees author)
- Comments + threaded replies
- Reactions

## Epic 4: Chat/DM
- Lobby (default)
- Rooms
- “סגולות” (instant DM) + “אדומות” (mailbox-like)
- Membership enforcement
- Tenure gating (7 days) + UX explanations

## Epic 5: Reporting & Moderation
- Report flows from posts/comments/DM
- Admin queue + actions
- Audit log + evidence snapshot policy

## Epic 6: Groups
- Group lifecycle + membership
- Visibility rules
- Group-scoped content

## Epic 7: Notifications
- Push/email hooks (phase later)
- Preference center

## Epic 8: Platform / Ops
- CI/CD
- Environments & secrets
- Monitoring & incident response
