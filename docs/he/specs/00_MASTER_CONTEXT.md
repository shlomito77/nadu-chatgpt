# NADU — הקשר־על (Master Context)

**סטטוס:** טיוטה (ננעל לאחר אישור)  
**עודכן לאחרונה:** 2026-01-07  
**מטרה:** זהו קובץ האמת היחיד לכל החוקים הגלובליים של NADU.

## 1) חזון
NADU היא פלטפורמה חברתית **למשתמשים רשומים בלבד** (18+) לקהילת ה‑BDSM בישראל, עם דגש על:
- **פוסטים** (פיד בסגנון פייסבוק)
- **צ'אט** (לובי + חדרים)
- **הודעות ישירות**:
  - **סגולות** = מיידיות (וואטסאפ)
  - **אדומות** = “דואר” (אימייל)

תוכן לא נגיש בכלל למי שלא רשום.

## 2) כללי־ברזל (Non‑negotiables)
### 2.1 בקרת גישה
- גולש אנונימי: **חסום מכל האפליקציה** (אין אפילו קריאה).
- רק **משתמש רשום עם פרופיל מלא** יכול לגשת לאזורים.
- כניסה לצ'אט יכולה לדרוש **וותק** (למשל 7 ימים) — כחוק מוצר.

### 2.2 מודל זהות
- זהות לפי **שם משתמש** (לא שם אמיתי).
- תווים מותרים בשם משתמש: **עברית / אנגלית / ספרות בלבד**.
- שם משתמש ותפקיד מופיעים בכל מקום (פוסטים/צ'אט/הודעות) למעט **פוסט/תגובה אנונימיים** שבהם יוצג `Anonymous`.
- שינוי שם משתמש: **פעם ב‑30 יום**.
- פרמטרים שאסור לשנות (נגד טרולים): **מין/מגדר**, **תאריך לידה** (גיל).

### 2.3 אנונימיות (תחום מוגבל)
- אנונימיות קיימת **רק** עבור:
  - יצירת פוסט
  - תגובה לפוסט (כולל תגובה לתגובה)
- אין אנונימיות בצ'אט או בהודעות.

### 2.4 שמירת מידע
- הודעות **סגולות** נשמרות.
- הודעות **אדומות** נשמרות.
- הודעות בצ'אט (לובי + חדרים) הן **זמניות**: ביציאה מהצ'אט המשתמש נכנס “לסשן חדש ונקי”.

### 2.5 בטיחות ומודרציה
- חסימה **הדדית**.
- **דיווח** חייב להיות אפשרי בכל מקום:
  - משתמשים
  - פוסטים/תגובות
  - הודעות (סגולות/אדומות)
  - הודעות צ'אט (לובי/חדרים)
- למנהל האתר יש **ויזביליות מלאה** כולל תוכן אנונימי.

## 4) קו טכני מוביל (כיוון נוכחי)
- Firebase (Auth + Firestore + Cloud Functions) עם Emulators לפיתוח.
- הלקוח כמעט Read‑Only; כל פעולות שינוי דרך **Cloud Functions** לשמירת אינבריאנטים.
- Firestore Rules מחמירים (“אין Edit/Delete מהלקוח”), כתיבות שרת דרך Admin SDK.

## 5) מילון קצר
- **יוזר/פרופיל**: אותו דבר (חשבון רשום + פרופיל מלא).
- **סגולות**: הודעות מיידיות.
- **אדומות**: הודעות דואר.
- **צ'אט**: לובי ציבורי + חדרים; הודעות זמניות.
