# 70 — ביצועים וסקיילינג

**עודכן לאחרונה:** 2026-01-07  
**סוג:** HOW

## 1) ברירות מחדל חסכוניות (Firestore)
- דה‑נורמליזציה למונים (לייקים/תגובות) כדי להימנע מאגרגציות כבדות.
- פג'ינציה בכל מקום (פיד, תגובות, Threads).
- אינדקסים קומפוזיטיים לשאילתות נפוצות.
- להימנע מ‑fan‑out writes ב‑v1.

## 2) מדיה
- לשמור ב‑Cloud Storage (לא ב‑Firestore).
- וריאנטים מוקטנים למובייל להפחתת תעבורה.

## 3) שליטה בעלויות צ'אט
- שאילתות לפי “מאז sessionStart”.
- TTL רק אם צריך באמת.

## 4) תצפית (Observability)
- Cloud Logging לפונקציות
- דשבורד בסיסי: שגיאות, Latency, writes/day.
