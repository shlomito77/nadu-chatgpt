# 50 — צ'אט (טכני)

**עודכן לאחרונה:** 2026-01-07  
**סוג:** HOW

## 1) משטחים
- לובי צ'אט (ציבורי למשתמשים שעומדים בתנאי ותק)
- חדרים (נפתחים ע"י משתמשים; אפשר מגבלה)
- ה‑UX הוא “סשן חדש” בכל כניסה, בעוד שאופן שמירה/ניקוי נקבע במדיניות.

## 2) מסלול כתיבה מומלץ
Client → Cloud Function → Firestore
- ולידציה של חברות + ותק
- בדיקת חסימות/אביוז
- כתיבה עם serverTimestamp
- אפשרות לאירועי התראות

## 3) התנהגות זמנית (Ephemeral)
- UX מרכזי: “יציאה מהצ'אט = לובי נקי”.
- אפשרויות יישום:
  A) **בלי מחיקה**: שומרים הודעות אבל שואלים “מאז sessionStart”.
  B) **ניקוי TTL**: ג'וב שמוחק הודעות ישנות (חיסכון).
  מומלץ: A ב‑v1, להוסיף B רק אם העלויות דורשות.

## 4) Reply
- תמיכה ב‑replyToMessageId + snippet.

## 5) נוכחות
- נוכחות קלה עם RTDB או heartbeat ב‑Firestore (אופציונלי).
- v1 אפשר לוותר.
