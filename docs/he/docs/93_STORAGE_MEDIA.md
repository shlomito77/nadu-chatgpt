# Storage ומדיה

## דליים (buckets)
- `avatars/uid/...`
- `postMedia/postId/...`
- `profileMedia/uid/...`

## מודל העלאה (מומלץ)
1. הלקוח מבקש URL חתום דרך `mediaCreateUploadUrl`.
2. השרת מחזיר URL + נתיב אובייקט צפוי.
3. הלקוח מעלה ישירות ל־Storage.
4. טריגר finalize בודק קובץ (type/size), יוצר מסמך מדיה, ומפעיל טשטוש אם צריך.

## מגבלות ברירת מחדל
- אווטר: ריבוע, עד 1024px, WebP/JPG, עד ~1–2MB.
- מדיה בפוסט: הגבלת כמות וגודל; תמונות בשלב 1, וידאו בהמשך.

## פרטיות
- Storage rules: העלאה רק לבעלים; קריאה תלויה ב־visibility ומטאדאטה מאושר.
