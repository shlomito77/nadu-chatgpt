# צינור מודרציה

## מטרות
- דיווח מהיר על הטרדות/סקאם/התחזות
- תיעוד מלא (audit)
- מינימום ממשק מנהל ב־v1, הרחבה בהמשך

## UX דיווח
- בכל הודעת DM/צ'אט, הודעה אדומה, פוסט, תגובה, פרופיל — כפתור “דווח”.
- הדיווח כולל:
  - קטגוריה
  - תיאור חופשי (חובה)
  - snapshot ראיות (ref + חלון הקשר)

## טיפול שרת
- `reportCreate` שומר `reports/{id}`.
- אופציונלי triage:
  - סף דיווחים → mute זמני
  - קטגוריות חמורות → תור בדיקה מיידי

## פעולות מנהל
- warn
- mute (צ'אט+DM) לזמן מוגבל
- חסימת שליחת אדומות לזמן מוגבל
- ban
- הסרת תוכן (פוסט/תגובה/הודעה)

## Audit
- כל פעולה יוצרת `moderationActions/{id}` עם evidence refs.
